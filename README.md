# Automatic Guitar Tuner

Прошивка автоматичного тюнера на ESP32-S3 (N16R8): мікрофон ICS-43434 визначає ноту, кроковий двигун 28BYJ-48 обертає кілок. Опис проєкту, теорія, схема та результати — у звіті.

## Збирання та прошивання

Потрібен [PlatformIO](https://platformio.org/) (CLI або розширення для VS Code).

```sh
pio run                      # зібрати
pio run --target upload      # прошити (кабель у роз'єм USB, не UART)
pio device monitor           # Serial Monitor, 115200
```

Перед підключенням до ноутбука вимкніть перемикач акумулятора, щоб плату не живили два джерела одночасно. Після старту ~1 с тиші: програма вимірює фоновий шум.

## Підключення

| Модуль | Сигнал → GPIO |
| --- | --- |
| ICS-43434 (I2S) | SD → 1, SCK → 2, WS → 41, L/R → GND |
| ST7789 1,54" (SPI) | SCL → 16, SDA → 15, RST → 7, DC → 6, CS → 5, BL → 4 |
| ULN2003 | IN1–IN4 → 10, 11, 12, 13 |
| INA219 (I2C, 0x40) | SDA → 9, SCL → 14 |
| Кнопки (на GND) | MENU → 17, ◀ → 18, ▶ → 8, OK → 3 |

Живлення: акумулятор → TP4056 (B+/B−) → OUT+ → перемикач → INA219 → TPS61088 → 5 В на пін 5V плати і, паралельно, на драйвер двигуна. Драйвер не можна живити від піна 5V плати при живленні від USB: струму не вистачає.

## Керування

- **MENU** — меню (інструмент, стрій, режим Auto/Manual, мотор On/Off, Test — чверть оберту ◀/▶).
- **◀ / ▶** — у меню змінюють значення; у режимі Manual вибирають струну.
- **OK** — у меню зберегти й вийти; на головному екрані — зупинити двигун.

## Що налаштовується в коді

| Константа | Файл | Що робить |
| --- | --- | --- |
| `MOTOR_DIR` | `src/main.cpp` | Напрямок двигуна. Якщо послаблює замість підтягування — `-1` |
| `STEPS_PER_CENT` | `src/main.cpp` | Кроків на цент похибки. Двигун «перелітає» ноту — зменшити |
| `IN_TUNE_CENTS` | `src/main.cpp` | Допуск «налаштовано» (зараз 5 центів) |
| `JUMP_CENTS` | `src/main.cpp` | Наскільки може стрибнути нота, щоб не вважатися стороннім звуком (голос) |
| `MAX_ITER`, `MAX_TOTAL_STEPS` | `src/main.cpp` | Ліміти обертання за один сеанс |
| `BATTERY_FULL_V` | `src/battery.cpp` | Напруга повного акумулятора без зарядки (значення `rest` у Serial Monitor) |
| `BATTERY_ON_VIN_MINUS` | `src/battery.cpp` | Акумулятор підключено до VIN− INA219 (струм інакше від'ємний) |
| `CHARGER_DETECT` | `src/battery.cpp` | Показувати ⚡ при зарядці (визначається за напругою) |
| строї | `src/tunings.cpp` | Новий стрій — один рядок, ноти як MIDI-номери |

## Структура коду

| Файл | Призначення |
| --- | --- |
| `src/main.cpp` | Меню, налаштування, логіка налаштування струни |
| `src/audio.cpp` | Читання I2S в окремій задачі, автокореляція через FFT (esp-dsp) |
| `src/pitch.cpp` | Визначення висоти тону (McLeod), без залежностей від Arduino |
| `src/motor.cpp` | Кроковий двигун на апаратному таймері |
| `src/buttons.cpp` | Кнопки з усуненням брязкоту |
| `src/display.cpp` | Екран |
| `src/battery.cpp` | INA219: напруга, струм, % заряду |
| `src/tunings.cpp` | Інструменти та строї |
