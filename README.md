# Automatic Guitar Tuner

Автоматичний тюнер для гітари, бас-гітари та укулеле на **ESP32-S3**. Пристрій слухає струну через I2S-мікрофон, показує ноту й відхилення на дисплеї та обертає кілок кроковим мотором, доки струна не зазвучить чисто.

## Що вже працює

- Три інструменти: **гітара**, **бас-гітара (4 струни)** та **укулеле**, для кожного кілька стандартних строїв.
- **Автоматичний режим**: програма сама визначає, яку струну защипнули.
- **Ручний режим**: струну вибирають кнопками, і програма налаштовує саме її.
- Дисплей 240×240: нота, номер струни, частота, відхилення в центах, стрілка та підказка.
- Налаштування мотором зі зворотним зв’язком: поворот → повторне вимірювання → поворот, доки відхилення не стане меншим за ±5 центів.
- Меню на чотирьох кнопках. Вибрані інструмент, стрій і режим зберігаються у флеш-пам’яті й не скидаються після перезапуску.
- Мотор можна вимкнути в меню, тоді пристрій працює як звичайний тюнер.
- Унизу екрана показано напругу акумулятора, приблизний заряд у відсотках і струм споживання. Під час розряду акумулятора мотор блокується.

## Підключення

Усі з’єднання виконуйте на знеструмленій платі.

**Мікрофон Adafruit ICS-43434 (I2S)**

| Мікрофон | ESP32-S3 |
| --- | --- |
| 3V | 3V3 |
| GND | GND |
| DOUT | GPIO1 |
| BCLK | GPIO2 |
| LRCL | GPIO41 |
| SEL | Не підключати або GND/3V3 (програма сама вибирає активний канал) |

**Дисплей ST7789**

| Дисплей | ESP32-S3 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SCL | GPIO16 |
| SDA | GPIO15 |
| RES | GPIO7 |
| DC | GPIO6 |
| CS | GPIO5 |
| BLK | GPIO4 |

**Мотор (через ULN2003)**

| ULN2003 | ESP32-S3 |
| --- | --- |
| IN1 | GPIO10 |
| IN2 | GPIO11 |
| IN3 | GPIO12 |
| IN4 | GPIO13 |
| + / − | 5V / GND |

**Живлення**

```text
Акумулятор + ──► INA219 VIN+ ──► INA219 VIN− ──► TPS61088 IN+
Акумулятор − ─────────────────────────────────► TPS61088 IN− (GND)
TPS61088 OUT 5V ──► ESP32-S3 5V  і  ULN2003 +
TPS61088 GND    ──► ESP32-S3 GND і  ULN2003 −
```

INA219 вмикається в розрив плюсового дроту акумулятора, тому він бачить напругу акумулятора і весь струм, який споживає пристрій. Усі GND мають бути спільними.

**Не підключайте USB і акумулятор одночасно**, бо 5 В від перетворювача й від USB потраплять на одну лінію. Для прошивання вимикайте акумулятор.

Перетворювач TPS61088 лише підвищує напругу. Якщо на вашому модулі немає контролера заряду, Li-Po потрібно заряджати окремим зарядним модулем із захистом.

**Датчик INA219 (I2C)**

| INA219 | ESP32-S3 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO9 |
| SCL | GPIO14 |
| VIN+ | Плюс акумулятора |
| VIN− | Вхід + перетворювача TPS61088 |

Адреса I2C — стандартна `0x40` (перемички A0/A1 не запаяні). Піни SDA/SCL можна змінити в [`src/battery.cpp`](src/battery.cpp). Якщо датчик не знайдено, тюнер працює далі, тільки без рядка про акумулятор.

**Кнопки** — кожна кнопка однією ніжкою до GPIO, другою до GND:

| Кнопка | GPIO |
| --- | --- |
| MENU | 17 |
| PREV (◀) | 18 |
| NEXT (▶) | 8 |
| OK | 3 |

## Збирання та запуск

1. Зберіть прошивку: `pio run`
2. Підключіть плату через USB і завантажте прошивку: `pio run --target upload`
3. Відкрийте Serial Monitor: `pio device monitor --baud 115200`

Після ввімкнення на екрані з’являється напис **Quiet please...**. Приблизно 1 секунду програма вимірює фоновий шум кімнати і за ним встановлює пороги гучності. У цей час не грайте.

У Serial Monitor видно гучність, частоту, «чистоту» тону (clarity), стан програми та натискання кнопок. Це зручно для перевірки.

## Кнопки та меню

| Кнопка | На головному екрані | У меню |
| --- | --- | --- |
| MENU | Відкрити меню | Наступний пункт |
| PREV | Попередня струна (ручний режим) | Попереднє значення |
| NEXT | Наступна струна (ручний режим) | Наступне значення |
| OK | **Аварійна зупинка мотора** | Зберегти й вийти |

Пункти меню:

- **Instr** — інструмент.
- **Tuning** — стрій.
- **Mode** — Auto або Manual.
- **Motor** — On або Off.
- **Test** — перевірка мотора. PREV/NEXT повертають мотор на чверть оберту в один або в інший бік. Логіка налаштування при цьому не працює. Якщо мотор тут не крутиться, проблема в підключенні або живленні мотора, а не в програмі.

Після зміни інструмента стрій і струна скидаються на перші.

## Як користуватися

1. Виберіть у меню інструмент, стрій і режим.
2. Надягніть мотор на кілок потрібної струни.
3. **Auto**: защипніть струну, програма визначить її сама. **Manual**: спершу виберіть струну кнопками PREV/NEXT, потім защипніть її.
4. Мотор повертає кілок невеликими кроками. Між кроками програма знову вимірює висоту звуку.
   - Якщо звук затих, на екрані з’явиться **Pluck again**. Защипніть струну ще раз.
   - Якщо 10 секунд стоїть тиша, програма повертається в очікування.
5. Коли струна в межах ±5 центів, з’являється **TUNED!**. Переставте мотор на наступний кілок.

Підказки на екрані:

| Напис | Значення |
| --- | --- |
| `IN TUNE` | Струна в межах ±5 центів |
| `LOW - tighten` / `HIGH - loosen` | Мотор вимкнено: підтягніть або послабте струну вручну |
| `LOW - tuning up` / `HIGH - tuning dn` | Мотор налаштовує струну |
| `MOTOR +128` | Мотор зараз обертається на вказану кількість кроків |
| `Too far - by hand` | Відхилення більше за 700 центів. Мотор не рухається, підтягніть струну ближче вручну |
| `TUNED!` | Готово |
| `LIMIT - stopped` | Досягнуто ліміт обертів (захист) |
| `STOPPED` | Мотор зупинено кнопкою OK |
| `Charge battery` | Акумулятор розряджений (нижче 3,40 В), мотор заблоковано |

Нижній рядок екрана, наприклад `Battery 3.92V  71%  180mA`:

- сірий — акумулятор у нормі;
- жовтий — нижче 3,60 В, час заряджати;
- червоний — нижче 3,40 В. Мотор заблоковано, доки напруга не підніметься вище 3,50 В.

Якщо живлення йде лише від USB, у рядку буде `No battery (USB power)`. Відсотки — приблизна оцінка за напругою. Коли мотор крутиться, напруга просідає, тому показник тимчасово зменшується.

## Інструменти та строї

Струни перелічено від найтовщої до найтоншої.

| Інструмент | Стрій | Ноти |
| --- | --- | --- |
| Гітара | Standard | E2 A2 D3 G3 B3 E4 |
| Гітара | Drop D | D2 A2 D3 G3 B3 E4 |
| Гітара | Half-step dn | Eb2 Ab2 Db3 Gb3 Bb3 Eb4 |
| Гітара | Open G | D2 G2 D3 G3 B3 D4 |
| Гітара | DADGAD | D2 A2 D3 G3 A3 D4 |
| Бас | Standard | E1 A1 D2 G2 |
| Бас | Drop D | D1 A1 D2 G2 |
| Бас | Half-step dn | Eb1 Ab1 Db2 Gb2 |
| Укулеле | Standard | G4 C4 E4 A4 |
| Укулеле | Low G | G3 C4 E4 A4 |
| Укулеле | Baritone | D3 G3 B3 E4 |

Новий стрій додається одним рядком у [`src/tunings.cpp`](src/tunings.cpp). Ноти задаються номером MIDI (C4 = 60, кожен півтон +1), частота обчислюється автоматично.

## Калібрування мотора

Параметри задано на початку [`src/main.cpp`](src/main.cpp):

| Параметр | Значення | Призначення |
| --- | --- | --- |
| `MOTOR_DIR` | `1` | Напрямок. Якщо мотор послаблює струну замість підтягування, змініть на `-1` |
| `STEPS_PER_CENT` | `4.0` | Скільки кроків на один цент відхилення. Якщо мотор «перелітає» ноту, зменште це число. Якщо рухається надто повільно, збільште |
| `MIN_STEPS`, `MAX_STEPS` | `16`, `512` | Найменший і найбільший поворот за один раз |
| `MAX_ITER`, `MAX_TOTAL_STEPS` | `30`, 10 обертів | Захист від нескінченного обертання |
| `IN_TUNE_CENTS` | `5` | Допуск «настроєно» |
| `NOISE_MARGIN_ON`, `NOISE_MARGIN_OFF` | `14`, `6` дБ | Наскільки гучніше за фоновий шум має бути звук, щоб вважатися нотою. Гучність у дБFS: 0 — максимум мікрофона, тому реальні звуки мають від’ємні значення |

Порядок калібрування:

1. Злегка послабте струну і защипніть її. Мотор має її підтягнути. Якщо він послаблює, змініть `MOTOR_DIR`.
2. Розстройте струну приблизно на 30 центів і подивіться, за скільки кроків вона налаштується. Підберіть `STEPS_PER_CENT`.

## Обмеження

- Один мотор: його потрібно переставляти з кілка на кілок вручну.
- Низькі ноти баса (D1 ≈ 37 Гц) маленький мікрофон чує погано. Іноді визначається друга гармоніка, і нота може показуватися на октаву вище.
- В автоматичному режимі сильно розстроєна струна може бути прийнята за сусідню. Тоді скористайтеся ручним режимом.
- Під час руху мотора звук не аналізується. Після кожного повороту програма чекає приблизно 150 мс, доки в аналіз не потраплятиме лише новий звук.
- Програма не розрізняє джерела звуку, тому налаштовуйте в тиші, по одній струні.
- GPIO3 на ESP32-S3 є strapping-піном. Не тримайте кнопку OK натиснутою під час увімкнення плати.
