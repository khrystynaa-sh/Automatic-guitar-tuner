# Automatic Guitar Tuner

Прототип гітарного тюнера на **ESP32-S3** з мікрофоном **MAX9814**. Визначає частоту звуку, знаходить найближчу струну стандартного строю та показує, чи потрібно її підтягнути або послабити.

Мета проєкту — автоматичне налаштування гітари за допомогою мотора, який обертатиме кілок. **Поточна версія лише аналізує звук і виводить підказки в Serial Monitor; кілок потрібно обертати вручну.**

## Що вже працює

- Визначення основної частоти алгоритмом YIN у діапазоні 70–400 Гц.
- Вибір найближчої з шести струн стандартного строю.
- Виведення виміряної та цільової частот, відхилення в центах і напрямку налаштування.
- Калібрування порогу фонового шуму під час запуску.
- Позначка `IN TUNE`, якщо відхилення не перевищує ±5 центів. Це поріг у програмі, а не підтверджена точність вимірювання.

## Що потрібно

- Плата ESP32-S3 DevKitC-1. Поточна конфігурація задає 16 МБ Flash і режим пам’яті `qio_opi`; для іншого варіанта плати налаштування потрібно адаптувати.
- Мікрофонний модуль MAX9814.
- З’єднувальні дроти та USB-кабель із передаванням даних для живлення й прошивання плати.
- PlatformIO Core або VS Code з розширенням PlatformIO IDE.

Прошивка написана на C++ з Arduino framework. Додаткових бібліотек у конфігурації немає.

## Підключення

Підключіть мікрофон до знеструмленої плати:

| MAX9814 | ESP32-S3 |
| --- | --- |
| VDD | 3V3 |
| GND | GND |
| OUT | GPIO1 |
| GAIN | Не підключати |
| AR | Не підключати |

У цій конфігурації мікрофон живиться від **3,3 В**. Для першого запуску живіть плату через USB; акумулятор і мотор не потрібні.

## Збирання та запуск

Завантажте репозиторій і відкрийте термінал у його кореневій папці. У VS Code можна використати термінал PlatformIO Core CLI.

**Зверніть увагу:** файл конфігурації в репозиторії має назву `platfromio.ini` замість стандартної `platformio.ini`. Тому в командах нижче його явно задано параметром [`--project-conf`](https://docs.platformio.org/en/latest/core/userguide/cmd_run.html#cmdoption-pio-run-c).

1. Зберіть прошивку:

   ```sh
   pio run --project-conf platfromio.ini
   ```

2. Підключіть плату через USB і завантажте прошивку:

   ```sh
   pio run --project-conf platfromio.ini --target upload
   ```

3. Відкрийте Serial Monitor зі швидкістю 115200 бод:

   ```sh
   pio device monitor --baud 115200
   ```

4. Перезапустіть плату кнопкою Reset і зберігайте тишу до повідомлення:

   ```text
   Guitar tuner ready. Play a string.
   ```

   Після початкової затримки у 2 секунди програма приблизно секунду вимірює фоновий шум.

5. Розташуйте мікрофон за кілька сантиметрів від резонаторного отвору гітари. Защипніть одну відкриту струну, приглушивши інші, і налаштовуйте її за підказками.

## Як читати результат

Приклад рядка в Serial Monitor:

```text
String 5 (A2) | 112.80 Hz | target 110.00 Hz | +43.5 cents | LOOSEN (pitch down) a little, 2.80 Hz
```

Тут п’ята струна звучить вище за цільову частоту на 2,80 Гц, тому її потрібно послабити. Центи показують відхилення висоти тону: 100 центів дорівнюють одному півтону.

| Підказка | Дія |
| --- | --- |
| `TIGHTEN (pitch up)` | Підтягнути струну, щоб підвищити тон |
| `LOOSEN (pitch down)` | Послабити струну, щоб знизити тон |
| `IN TUNE` | Струна в межах допуску ±5 центів |

Слова `slightly`, `a little` та `a lot` описують величину відхилення, а не конкретний кут повороту кілка. Повертайте кілок поступово та повторно защипуйте струну.

Підтримується стандартний стрій, від найтовстішої струни до найтоншої:

| Струна | Нота | Цільова частота, Гц |
| --- | --- | --- |
| 6 | E2 | 82,41 |
| 5 | A2 | 110,00 |
| 4 | D3 | 146,83 |
| 3 | G3 | 196,00 |
| 2 | B3 | 246,94 |
| 1 | E4 | 329,63 |

## Код і налаштування

Уся логіка міститься в [`src/main.cpp`](src/main.cpp), параметри плати та збирання — у [`platfromio.ini`](platfromio.ini).

Програма зчитує блок звуку, прибирає постійну складову та відкидає надто тихі блоки. Далі YIN оцінює частоту, а програма порівнює її з частотами струн і друкує підказку.

Основні параметри можна змінити на початку `src/main.cpp`:

| Параметр | Значення | Призначення |
| --- | --- | --- |
| `MIC_PIN` | `1` | GPIO аналогового виходу мікрофона |
| `SAMPLE_RATE` | `8000` | Задана частота дискретизації, Гц |
| `N` | `2048` | Кількість відліків у блоці; за 8 кГц це 256 мс звуку |
| `MIN_FREQ`, `MAX_FREQ` | `70`, `400` | Робочий діапазон частот, Гц |
| `YIN_THRESHOLD` | `0.15` | Поріг прийняття оцінки періоду в YIN |
| `IN_TUNE_CENTS` | `5.0` | Допуск для позначки `IN TUNE` |

## Обмеження та типові проблеми

- **Немає показів після защипування.** Перевірте підключення, наблизьте мікрофон до резонаторного отвору та перезапустіть плату в тиші. Шум під час калібрування може завищити поріг спрацювання.
- **Покази реагують на голос або сторонні звуки.** Програма не розрізняє джерела звуку, тому тестуйте в тихому приміщенні, по одній струні.
- **Визначається інша струна.** Програма вибирає найближчу ноту стандартного строю. Для сильно розстроєної струни цей вибір може бути неправильним; ручного вибору струни поки немає.
- Точність ще потребує перевірки за еталонним тюнером. Захоплення одного блоку займає близько 256 мс, після чого потрібен час на обробку.
